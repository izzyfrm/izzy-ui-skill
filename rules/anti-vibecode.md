# Anti-Vibecode Rules

The interface should not look like it came from the same generic AI website template used everywhere else.

Avoid these patterns unless the product or user specifically calls for them:

- purple-to-blue gradients as the default brand treatment
- gradient headline text
- random glowing blobs or background beams
- glassmorphism on every surface
- excessive blur and transparency
- every section placed inside a rounded card
- generic three-card feature rows
- meaningless badges above hero headlines
- emoji in section headings
- giant hero areas with little useful content
- decorative dashboard numbers with no real product purpose
- excessive icon usage
- using icons where plain text is clearer
- the same rounded rectangle shape for every component
- excessive pill-shaped buttons and labels
- low-contrast gray-on-gray dark themes
- enormous border radii everywhere
- excessive shadows
- fake testimonials, metrics, activity feeds, or charts
- generic copy such as "supercharge your workflow" when the product has a more specific value
- animating every section into view
- cursor-following lights or beams without a strong reason
- adding visual complexity to make the page feel more "premium"

## Better approach

Before adding a decorative element, ask what problem it solves.

Before adding another card, ask whether spacing or a divider would communicate the grouping better.

Before adding an icon, ask whether the label already explains the action.

Before adding animation, ask whether the state change is understandable without it.

The goal is not minimalism at all costs. The goal is intentional design.
