# Example Prompts

## Build

```text
Use the izzy-ui skill to build a clean landing page for my Discord bot. Keep it dark, simple, responsive, and avoid generic AI SaaS styling.
```

## Redesign

```text
Use izzy-ui to redesign this page without changing the existing functionality. Improve hierarchy, spacing, responsiveness, and overall polish. Remove anything that feels unnecessarily decorative.
```

## Mobile pass

```text
Use izzy-ui to fix the mobile experience. Do not simply shrink the desktop layout. Rework navigation and spacing where necessary while preserving all features.
```

## Dashboard

```text
Use izzy-ui to build this dashboard around the actual tasks users perform. Keep the data easy to scan and do not invent cards, metrics, or charts just to fill space.
```

## Apple-like direction

```text
Use izzy-ui with the Apple-like preset. Keep it polished and restrained. Do not overuse blur, glass, or giant rounded surfaces.
```
