# Style Presets

Presets are starting directions, not rigid themes. Adapt them to the product instead of copying them literally.

## Apple-like

Use when the user wants a calm, polished, product-first interface.

- generous but controlled spacing
- strong typography hierarchy
- restrained color
- subtle depth
- smooth state transitions
- simple controls
- clear focus on content

Do not turn "Apple-like" into glass everywhere. Use translucency only where layering or context benefits from it.

## Minimal Dark

Use for developer tools, media products, dashboards, and focused utilities.

- near-black or deep neutral background
- clear text hierarchy
- restrained borders
- limited accent color
- compact navigation
- little to no decorative glow

Dark does not mean low contrast.

## Developer

Use for technical products where clarity and density matter.

- practical information hierarchy
- monospace used selectively for code, IDs, logs, or metadata
- compact but readable controls
- strong status states
- clear tables, filters, and empty states
- minimal decorative UI

## Dashboard

Use for data-heavy interfaces.

- prioritize scanning and comparison
- group data by task, not by visual symmetry
- charts must answer a real question
- use cards only where grouping is helpful
- keep filters near the data they affect
- avoid filling empty space with fake metrics

## Editorial

Use for portfolios, publications, storytelling, and content-first sites.

- typography carries the visual identity
- deliberate reading width
- clear rhythm between sections
- imagery receives room to breathe
- fewer interface containers
- restrained controls and decoration
